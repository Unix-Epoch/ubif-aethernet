Aethernet Install Guide

Restoring the flow of NextGen · setup takes about 5 minutes

Before you start

  • A computer browser: Google Chrome or Microsoft Edge (recommended). Firefox also works.
  • Your Portal sign-in. Aethernet runs inside Portal at portal.ubreakifix.net.
  • Store access. Aethernet is turned on store by store. If your store isn't on yet, Portal will say so after you install (see Troubleshooting).

Install

1
Add the Tampermonkey extension

Tampermonkey is a free browser extension that runs add-ons like Aethernet. Get it from your browser's store:

  • Chrome: Chrome Web Store, search “Tampermonkey”, then Add to Chrome.
  • Edge: Edge Add-ons, search “Tampermonkey”, then Get.
  • Firefox: Firefox Add-ons, search “Tampermonkey”, then Add to Firefox.

Violentmonkey works too. Greasemonkey does not.

2
Chrome and Edge only: allow user scripts

Without this, Tampermonkey installs fine but nothing runs.

  • Go to chrome://extensions (Edge: edge://extensions).
  • Find Tampermonkey and click Details.
  • Turn on Allow User Scripts. On older browser versions this switch doesn't exist; turn on Developer mode (top right of the extensions page) instead.
3
Open the install link

Paste this into the address bar:

https://gist.githubusercontent.com/Unix-Epoch/0cf4560c4f26d8ff9091a10068fd3464/raw/aethernet.user.js

Tampermonkey opens its own install page for Aethernet. Click Install.

4
Refresh Portal

Reload any open Portal tabs (or open Portal and sign in). Aethernet loads with Portal.

5
Check that it's working

Click your picture in Portal's top right corner. The menu now has Aethernet settings. That's where you turn each tool on or off and read the patch notes.

Tip: Aethernet's tools are called crystals. Each one has a short description in Settings.

Updates

  • Tampermonkey checks for a new version about once a day and installs it by itself.
  • When an update is out, Aethernet shows an update available note. Click it, then Update on Tampermonkey's page, then refresh Portal.
  • You can check any time: Aethernet settings → Check for updates.
  • After an update, a short “Aethernet has updated!” note appears once. New or changed crystals are highlighted in Settings.

Troubleshooting

What you seeWhat to do
Nothing changes in Portal, and no Aethernet settings in the menuCheck step 2 (Allow User Scripts). Make sure Tampermonkey and the Aethernet script are both switched on in Tampermonkey's dashboard. Then refresh Portal.
“Aethernet isn't available for [store] yet”Your store isn't turned on yet. Ask your manager to request access.
“Aethernet couldn't check this store's access”A temporary connection problem. Aethernet keeps trying; refresh Portal in a few minutes.
Buttons show up twiceAn older single-tool script is still installed. In Tampermonkey's dashboard, remove every script except Aethernet.
Something looks wrong or brokenClick your picture in Portal, then Send feedback. Choose bug or suggestion; bug reports include the details needed to fix it.
Good to know: Aethernet only runs on Portal. It works in every Portal tab you have open, and it uses your own Portal sign-in. It never asks for a password.
